# 04 — Matemática Correlacional

C = espacio de correlaciones (Silencio nodal).
Psi = sum alpha_i |c_i>
Delta = diferenciación. Lambda = coherencia (Amor). Theta = conciencia / integración.

Ecuación maestra: d|Psi>/dtau = -i[H,|Psi>] + gamma Delta|Psi> - beta Lambda|Psi> + epsilon
Tiempo térmico emerge cuando dS/dtau > 0.
